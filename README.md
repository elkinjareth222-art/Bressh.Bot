# Bressh.Bot Landing Page

This repository contains a modern landing page for `Bressh.Bot`, designed with a blue and sky palette and aimed at Discord communities.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` – main page structure
- `styles.css` – layout and visual design
- `script.js` – small frontend behavior

## Project goal

Promote a Discord bot/brand with a vibrant landing page focused on automation, moderation, and community growth.
